# HW4 - 3D Flying Game

## 一、作品介紹

本專案為 Unity 3D 飛行遊戲，玩家需要控制飛機在場景中前進，並透過方向控制閃避障礙物、穿越指定通道。

遊戲包含飛機移動、攝影機跟隨、障礙物碰撞判定、成功通過計分，以及遊戲結束與重新開始功能。

## 二、開發環境

- Game Engine：Unity 6.6
- Programming Language：C#
- IDE：Visual Studio
- Platform：Windows

## 三、遊戲操作方式

| 按鍵 | 功能 |
|---|---|
| W | 向上移動 |
| S | 向下移動 |
| A | 向左移動 |
| D | 向右移動 |

飛機會持續向前飛行，玩家需要控制飛機通過障礙物。

## 四、遊戲功能

1. 飛機自動向前移動。
2. 使用鍵盤控制飛機方向。
3. 攝影機跟隨飛機移動。
4. 設置障礙物與通過區域。
5. 成功通過障礙物後增加分數。
6. 碰撞障礙物後觸發 Game Over。
7. 提供重新開始功能。
8. 加入飛行、碰撞及成功通過三種音效。

## 五、使用技術

- Unity 3D 場景建置
- C# 程式設計
- Rigidbody 物理移動
- Collider 碰撞偵測
- Trigger 觸發判定
- TextMeshPro UI
- AudioSource 音效播放

## 六、專案製作流程

1. 建立 Unity 3D 專案。
2. 建立飛機模型與場景。
3. 設置障礙物與通過區域。
4. 撰寫飛機控制程式。
5. 加入攝影機跟隨功能。
6. 建立分數及遊戲結束系統。
7. 加入三種遊戲音效。
8. 測試遊戲操作與碰撞功能。
9. 上傳專案至 GitHub。
